# Superstore Sales & Profit Analysis

This project analyzes Superstore sales data to understand sales performance, profitability, customer segments, product categories, and regional trends.

## Tools Used

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Power BI

## Project Objectives

- Analyze overall sales and profit
- Identify profitable and loss-making categories
- Understand regional sales performance
- Analyze customer segments
- Find useful business insights from the data
- Build an interactive Power BI dashboard
