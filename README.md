# Superstore Sales & Profit Analysis

This project analyzes the Sample Superstore dataset to understand sales performance, profitability, customer segments, product categories, and regional trends. An interactive Power BI dashboard was created to present the analysis and business insights.

## Tools Used

* Power BI
* Power Query
* Python
* Google Colab
* Pandas
* NumPy
* Matplotlib
* Seaborn

## Project Objectives

* Analyze overall sales and profit
* Identify profitable and loss-making categories and sub-categories
* Understand regional sales and profit performance
* Analyze customer segments
* Identify important business insights
* Build an interactive Power BI dashboard

## Key KPIs

| KPI            |    Value |
| -------------- | -------: |
| Total Sales    |   $2.30M |
| Total Profit   | $286.40K |
| Total Quantity |   37,873 |
| Profit Margin  |   12.47% |

## Power BI Dashboard

The dashboard contains the following analysis pages:

1. **Overall Sales Analysis**
2. **Region Analysis**
3. **Sub-Category Analysis**
4. **Category Analysis**
5. **City Analysis**

## Key Insights

* Technology generated the highest sales and profit among the three main categories.
* The West region recorded the highest overall sales and profit.
* Tables were the largest loss-making sub-category.
* The Consumer segment contributed the highest sales and profit among the customer segments.
* 2017 recorded the highest annual sales and profit in the dataset.

## Dataset

The project uses the **Sample Superstore** dataset containing 9,994 records and 21 columns covering orders, customers, products, sales, discounts, and profits.
